# Mobile Price Classification using Logistic Regression

This project trains a Logistic Regression model to classify mobile phones into two price categories.

## Classes
0 → Basic Price  
1 → Premium Price

## Steps Performed
- Loaded the dataset
- Checked for missing values
- Converted the original 4 price ranges into 2 classes
- Split the data into training and testing sets
- Trained a Logistic Regression model
- Evaluated model accuracy
- Generated predictions for the test dataset

## Tools Used
Python  
Pandas  
NumPy  
Scikit-learn  

## Files in this Project
train.csv – training dataset  
test.csv – testing dataset  
model.py – machine learning code  
predictions.csv – predicted results
